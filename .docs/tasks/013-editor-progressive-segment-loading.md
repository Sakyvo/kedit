## What to build

编辑器侧渐进载入：打开不卡死、滚到即载、全选不丢字。

- **首段先行**：打开文档时只同步渲染首个分段（含光标/滚动位置所在段），
  目标 1 秒内可输入可滚动；其余分段以**空占位**（估算高度的 div）占位。
- **空闲补齐**：requestIdleCallback/分片调度在后台逐段补渲染，终态为全量
  DOM；补齐期间击键优先（输入事件可打断/推迟补齐切片）。
- **到达即载**：滚动或跳转（TOC/查找/光标移动）临近未载入段时立即同步
  渲染该段；占位高度在实渲后修正，滚动位置随之微调（接受轻微跳动）。
- **O(1) 增量测量**：尺寸测量只在受影响分段上执行，其后分段偏移量加 delta
  平移，废弃全量 offsetTop 链。
- **模型层全选**：Ctrl+A 全选后的复制/剪切/删除整篇一律由模型供全文
  （硬性验收项）；跨占位的局部选择走模型计算选区文本。
- 图片卡片、讨论锚点等按段载入时随段重建。

## Acceptance criteria

- [ ] `npm run build` 通过
- [ ] 80 万字文档打开后 1 秒内（首段）可输入；补齐期间输入不被冻结
- [ ] 滚动到任意未载入段时即时可见该段内容，补载后无文本错乱（对账通过）
- [ ] Ctrl+A → 复制得到完整全文（无论当前载入进度）；剪切/删除整篇后模型为空
- [ ] 长文档输入时不再发生全量尺寸测量（打点佐证）
- [ ] 开关 OFF 时旧路径不受影响
