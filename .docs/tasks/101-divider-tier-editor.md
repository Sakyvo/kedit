## What to build

编辑区里敲 `---` / `------` / `---------` 得到三档不同颜色的标记串（原色 / 蓝 / 红），任何编辑主题下都不变形。档位由源行的标记字符数决定，与预览共用同一张档位表。工具栏「分割线」按钮改为插入原色档。

源文本仍是标准 CommonMark `hr`，只是渲染着色不同（ADR 0004）；档位的颜色与粗细由 KEDIT 独占（ADR 0017）。

## Acceptance criteria

- [ ] `---`、`----`、`-----` 标记串保持现行淡灰（`$editor-color-*-high`），无变化。
- [ ] `------` 至 `--------` 标记串为蓝 `#2e86c8`（深色主题 `#6fb5e6`）。
- [ ] `---------` 及以上为红 `#c0392b`（深色主题 `#e5735f`）。
- [ ] `- - - - - -` 与 `------` 同档；`******` / `______` 与 `------` 同档（标记字符数口径，空格不计）。
- [ ] 逐个切换全部 15 个内置编辑主题，三档颜色均不变形；再手写一段比现有主题特异性更高的自定义 `.editor__inner .hr` 规则，三档仍不变形。
- [ ] 工具栏「分割线」按钮插入的源文本为 `---`（不再是 10 个标记），Ctrl/Cmd+R 与工具栏按钮两条入口行为一致。
- [ ] 档位阈值只有一处定义（档位表常量），编辑区与预览各自引用它，不得各写一份数字。
- [ ] `npm run build` 通过；给出三档 × 亮/暗 × 至少两个主题的截图证据。
