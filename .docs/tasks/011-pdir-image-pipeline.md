## What to build

图片管线：发布时把 Document 引用的 `/imgs/` 私有图（仅本文档引用的）投影为 pdir
`imgs/` 下的公开图，并改写正文引用；解除 009 的拒图护栏。

- 命名图（alt ≠ `输入图片说明`，一律视为已命名）：文件名 = alt.真实扩展名（非法路径
  字符清洗）。冲突三档：内容相同→跳过；同名且被本 Module 当前正文引用→覆盖更新；
  同名但非本 Module 引用→后缀 `(1)` 避让。同批次内重名按 `(1)(2)` 顺延。
- 未命名图：延续 pdir 数字编号（起点 = max(imgs/ 目录数字文件名, main.md 数字引用)
  + 1），按文档出现顺序分配；命名图不进入排序计数。
- 幂等：本地计算 git blob sha 与仓库文件 sha 比对，内容相同复用现有文件名/编号，
  零重传。
- 引用改写为 `/imgs/<名>.<ext>`；alt 原样保留；外链图原样不转存。
- 顺序：图片先传、正文后写；不再引用的旧图不清理（孤儿留存，手动管理）。
- 合一弹窗展示图片统计（新传/复用/覆盖计数），与实际上传行为一致。
