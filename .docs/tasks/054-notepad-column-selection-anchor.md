# 054 矩形选择照搬 Notepad4 批次锚卡

## Problem

Author 在真机上验证 053 后判定「无效或者说错误」：按住 Alt 拖拽时**只画出了一个矩形框，文字并没有被选中**，与 Notepad4（`K:\Projects\dev\notepad420`）的矩形选区观感不符。根因已定位：拖拽期只渲染自绘边框、松手才算选区，且边界按"行尾截断"处理，短行不留虚拟空间。Author 明确要求「全部照搬 notepad 的」。

## Decisions

grill 收敛，Author 全数确认（决策背景与被否方案见 ADR 0014「矩形选择照搬 Notepad4 语义」）：

1. **拖拽期实时选区**：Alt 按下即进入，mousemove 每次立刻逐行重算并重绘（Scintilla `SetRectangularRange` 语义）——呈现的是"文字被选中"，绝不画空框。
2. **边界 = 鼠标像素 x**，逐行独立换算（`SPositionFromLineX` 语义），取消"行尾截断"。
3. **虚拟空间**（`SCVS_RECTANGULARSELECTION`）：超出短行行尾的部分照选；短行缺失段以同色实心补齐 → 视觉为整齐矩形块。
4. **粘性多行插入**（`ThinRectangularRange`）：首键替换各行列段后，选区收成零宽列光标，继续打字继续逐行插入；Esc / 单击 / 方向键 / Enter 退出。
5. **短行按下打字自动补空格**到该列（`RealizeVirtualSpace`）——真实内容变更，会进文档与同步（照搬的必然代价）。
6. **列删除**：有选区时删各行列段；零宽列光标时 Backspace 删各光标左一字符、Delete 删右一字符。
7. **列粘贴**：自己的列复制 → 逐行带空格补齐贴入；外来文本 → 先清空矩形内真实字符，再在左上角整段插入。
8. **拖出视口自动滚动扩选**。
9. **Alt 仅按下时判定**，拖拽中松开继续矩形；Ctrl+C/X 仍作用于列内容；连续按键经 `typing` 模式合并为单个 undo 单元。

## Out of scope

- cledit 选区/undo/IME 架构级真多光标（多行光标仍以列模式内整段字符串变换实现）。
- 触屏/移动端列选择。
- 自动滚动的惯性/变速细节（匀速贴边滚动即可）。
- `053` 卡的历史记录保留不动；本批次是其行为替换。

## Testing strategy

Jest 链已断，唯一 CI 门槛 `vite build`（git-bash 下嵌套 npm 会段错误，拆步 `npx vite build --mode production` + style 子链）。纯变换层用独立 Node 断言脚本（手算基准，红→绿）；DOM 层无 GUI 接缝，按后台静态验证 + 真机人工验收清单交付（不阻塞、不标 blocked）。
